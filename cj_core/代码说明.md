# cj_core — 仓颉编译工程

本目录为 `semanticvg-cj` 的 **可编译仓颉工程**（包名 `semanticvg_cj`）。

与交付件目录 `01_向量组数据结构仓颉实现代码/` 的对应说明见：`../01_向量组数据结构仓颉实现代码/代码说明.md`。

## 运行

```powershell
cd semanticvg-cj\cj_core
cjpm run
```

## 为何单独放在 cj_core

仓颉工具链 `cjpm` 在**父路径含中文**时会报 `Invalid unicode scalar value`，无法扫描源码。本仓库将 `cjpm.toml` 与 `src/` 放在 ASCII 路径 `cj_core/`，`01_...` 仅保留与第二阶段交付件一致的文档位置。
